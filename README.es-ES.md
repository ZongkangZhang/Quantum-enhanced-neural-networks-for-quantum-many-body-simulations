# Redes neuronales mejoradas con quantum para simulaciones de muchos cuerpos cuánticos

Este repositorio contiene el código y los datos que acompañan al siguiente artículo:

- Zongkang Zhang, Ying Li y Xiaosi Xu, “Redes neuronales mejoradas con quantum para simulaciones de muchos cuerpos cuánticos”, *PRX Intelligence* **1**, 013002 (2026).  
  https://doi.org/10.1103/2jpn-jh3x

## Requisitos

El código está escrito en Python y utiliza las siguientes bibliotecas:

- [PyTorch](https://pytorch.org/) para la implementación de las redes neuronales.
- [PennyLane](https://pennylane.ai/) para la construcción de circuitos cuánticos.
- [OpenFermion](https://quantumai.google/openfermion) para la generación de Hamiltonianos moleculares.
